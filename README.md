# 🌐 Portfólio Pessoal - Gabriel Vinicius de Morais

Bem-vindo ao repositório do meu portfólio web! Este projeto foi desenvolvido para apresentar minha trajetória acadêmica, experiências profissionais e projetos em desenvolvimento na área de tecnologia.

---

## 📌 Sobre o Projeto

O site tem como objetivo central disponibilizar uma interface limpa, rápida e acessível para quem deseja conhecer mais sobre meu trabalho e entrar em contato.

### 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de páginas web.
* **CSS3:** Estilização responsiva e padronização visual.
* **JavaScript (ES6+):** Lógica dinâmica de interação e consumo de APIs.
* **GitHub Pages:** Hospedagem e deploy contínuo da aplicação.

---

## 📂 Estrutura de Páginas

* **Início (`index.html`):** Apresentação geral do site.
* **Sobre Mim (`sobre.html`):** Informações sobre minha trajetória e interesses.
* **Formação (`formacao.html`):** Detalhes da graduação em Engenharia de Software e idiomas.
* **Portfólio (`portfolio.html`):** Lista de projetos desenvolvidos.
* **Contato (`contato.html`):** Meios de contato e mural interativo de mensagens.
